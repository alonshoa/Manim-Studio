# Example assets — publication checklist

The two end-to-end walkthroughs are adapted from the reviewed documentation package. The binary media has not yet been uploaded. This draft intentionally does not link to nonexistent downloads.

Before marking the pull request ready:

- Review source archives, original teaching material and captured messages for publication rights and private information.
- Publish the original and final PowerPoint files, full previews, individual scene videos and stills, and reusable source packages using a stable public asset host (prefer GitHub Release assets for large downloads).
- Restore the inline video players and stills from the reviewed Markdown pages, using the actual published URLs; retain final-scene versus historical-draft labels.
- Include the reviewed conversation, scene catalogs and storyboards; do not publish raw research logs.
- Run `mkdocs build --strict` and verify playback and download links on the deployed preview.

The documentation branch deliberately avoids committing the approximately 187 MB review package to Git history.
