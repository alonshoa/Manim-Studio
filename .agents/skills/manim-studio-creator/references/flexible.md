# Flexible workflow

Start from the user's current request and the existing project state. Do not force a complete questionnaire or all guided checkpoints.

Offer a brief plan only when it would avoid rework. Allow the user to move freely among narrative, storyboard, code, render and revisions. Before destructive changes or major scope changes, confirm intent. Validate rendered results and state clearly what was or was not checked.

If the user requests a structured review, switch to Guided mode without discarding completed work.
