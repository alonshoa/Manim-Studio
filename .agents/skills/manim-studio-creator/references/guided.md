# Guided workflow

1. Establish audience, learning objectives, prior knowledge, output format and constraints.
2. Draft a concise teaching narrative and scene/slide outline. Obtain user approval before proceeding.
3. Produce a visual storyboard: what appears, transitions, pacing, and emphasis. Obtain approval before implementation.
4. Inspect existing project structure and available Studio commands; implement in small reviewable increments.
5. Render in draft quality and inspect the output; revise based on feedback.
6. Build/export only when requested; provide artifact locations and a concise validation summary.

Do not jump to code before the user approves the narrative and storyboard. Ask only questions that materially affect the work.
